# Triptych sample vault

An Obsidian vault for the FirstPair Triptych plugin: three drafts (Draft 1, Draft 2, Final) of a short essay, *The Ferry at Low Water*, in two Parts and six pages, shown in two sets. Open the folder as a vault, install `plugins/firstpair-triptych` into `.obsidian/plugins/`, enable it, and start from `Home.md`.

The essay was written for this sample; it and the vault are MIT licensed like the rest of the repository. Edition commits are placeholders.

The vault is generated: run `python3 samples/build/build_triptych.py` from the repository root, and check it with `node samples/build/check-triptych.mjs`.
